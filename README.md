# Password Generator 🔐

A simple and user-friendly Password Generator built using Python and Tkinter. It helps generate random passwords with different combinations of letters, numbers, and special characters.

# Features

Generate random passwords
Set custom password length (4–64 characters)
Include uppercase and lowercase letters
Include numbers and special characters
Copy password with one click
Simple and clean GUI

# Technologies Used

Python
Tkinter
String Module
Secrets Module
